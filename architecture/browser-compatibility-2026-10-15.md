# 浏览器白屏兼容修复 · 2026-10-15

用户反馈部分老款 Windows 10 自带浏览器打开正式站白屏，并要求尽可能兼容，无法兼容时明确说明。本次沿用原站 https://dianqisim.com/ ，不新增域名、源站、账号或数据库。

## 根因与实现

实际编辑器在渲染时直接调用 `selectedWires.at`。在删除该接口的独立 Node/React 渲染环境中，修改前复现 `selectedWires.at is not a function`；这能解释一类白屏，但没有取得故障电脑的版本和控制台，不能断言每台故障电脑均为同一原因。

- 增加按需 `Array.prototype.at` 和基于 `crypto.getRandomValues` 的安全 UUID 兼容；保留浏览器已有实现，不使用弱随机数。
- 电路文档是共享 JSON 契约；缺少 `structuredClone` 时只对该文档使用 JSON 深拷贝，不伪造通用结构化克隆。
- 正式成员站与 Pages 脚本构建目标从 ES2022 调整到 ES2020。语法降级不等于所有浏览器接口都被兼容，也不是最低浏览器版本保证。
- HTML 初始内容包含加载提示；独立 ES5 启动脚本提供过旧浏览器、脚本加载失败和应用启动失败提示及手动重载入口。React 未捕获错误回到可读提示，不自动重试任何业务写入。
- IE11、旧 EdgeHTML 和兼容模式明确提示使用新版 Edge/Chrome；360/QQ 等双内核浏览器提示切到极速模式。新旧草稿、作品与附件契约没有变化，不执行 SQL 迁移。
