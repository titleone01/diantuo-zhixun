# 二维教学电气规则与判定边界

更新：2026-09-30。适用新 `app/simulator/`，不修改遗留三维模块的判定规则。

## 三层结果

1. **运行状态**：`simulate(document, runtime, action)` 返回由当前接线和操作推导出的器件状态。错误接线导致保护失效时，电机仍可能受电，不能用“过载标志=true”直接强制停机来掩盖旁路。
2. **诊断**：短路、电压类别错误、PE 缺失、未支持的负载网络分别报告。危险故障停止的是教学电源；这不是对真实断路器动作时间、熔芯熔断或人身安全的仿真。
3. **课程判定**：`assessLesson` 在副本中执行操作并检查保护路径、课程目标和可达状态。电机能转、灯会亮都不足以单独证明接线正确。

`supported` 表示离散模型能够处理当前网络，不能解释为电路安全。课程状态为 `passed`、`incomplete`、`failed` 或 `unsupported`；自由接线没有课程时不签发“正确”。

## 电气事实与绘图数据

- 文档保存实例、稳定端子引用和导线。图片、实例位置、导线颜色、直线/曲线/直角、折点和交叉点都不参与网络求解。
- 只有真实端子连接才构成电气节点。导线画面相交不产生接点；在同一螺丝上接多根线构成分支。
- 世界端点由 `实例 position + catalog 端子局部坐标` 得到；缩放/平移、移动元件、导出再导入都不改变端子引用。
- 原图 SVG 以原始纵横比显示，端子坐标由原图彩色圆圈中心标定。它们是二维教学图示，不能作为厂家真实尺寸或安装证据。电源为独立绘制的端子条；PE 端子复用原双极端子图的第一极。
- 原站社区作品仅用于观察产品交互，不是电气安全标准。原图中电机已有 PE 圈，本实现使它成为真实可接的 `PE` 端子。

## 模型规则表

| 对象/现象 | 当前实现 | 判定/显示 |
| --- | --- | --- |
| 电源 | 单组 L1/L2/L3/N/PE；不同相之间 380V，相与 N 之间 220V；N 与 PE 在训练板内独立 | 不计算瞬时波形、相位角或真实频率响应 |
| 导线/固定连接 | 零阻抗连接，使用并查集得到等电位网络，同时保留路径图 | 路径图提供元件、端子和导线证据 |
| 开关与触点 | 按当前动作决定是否合并两侧网络 | 分合闸/按钮变化后重建网络 |
| 线圈、灯、电机 | 负载不会被当成一条零阻抗导线 | 正常 L-N 或相间负载不会被错误报成短路 |
| 220V/380V 线圈 | 只接受其额定类别；同相两端为 0V，缺返回路径不吸合 | `COIL_VOLTAGE_MISMATCH` / `OPEN_CONTROL_PATH`；这不是厂家吸合/释放电压容差模型 |
| 接触器 | 主触点、13-14 常开及 21-22 常闭联动；上下 A2 永久相连 | 从前一时刻状态开始迭代，支持自锁；每次触点变化后检查新短路 |
| 复合按钮、限位开关 | 11-12 常闭，23-24 常开；转换先开后合，中间求一次稳定状态 | 防止混合点动按钮释放时利用旧 KM 状态误自锁；此为离散接触顺序，不模拟实际机械时间 |
| 热过载继电器 | TEST 锁存：95-96 开、97-98 合；RESET 恢复。主检测通道保持导通 | 只有正确接入控制回路，TEST 才会使接触器释放；不计算热模型或过载电流 |
| 三端电机 | U/V/W 得到三种不同相位才运行；循环相序为正向，交换两相为反向 | 缺相独立报告；课程分别验正向、反向。不计算启动电流、转矩、惯性、转速或温升 |
| 六端 Y/△ 电机 | 三组独立绕组；识别三相供电与浮动星点，或三组方向一致的相间绕组构成 △ | 开路返回 `MOTOR_WINDING_OPEN`；不支持/无效接法返回 `MOTOR_CONNECTION_INVALID`，不凭 KM 标签显示运行 |
| Δ/YY 双速电机 | 独立的外接模式：第一组三端供电且第二组外接隔离为低速；第二组三端供电、第一组共接浮动点为高速 | 不把内部误当成三组独立绕组；额外负载接浮动绕组端返回 `UNSUPPORTED_MOTOR_LOAD_NETWORK` |
| KA 与独立辅助块 | 380V KA NO/NC 随线圈；辅助 NO 实例以 `linkedTo` 绑定 KM/KA，电气触点保持隔离 | 未绑定可保存草稿，但运行返回 `AUXILIARY_OWNER_MISSING`；不同组 NO 不得共用同一对电气节点 |
| KT | 380V 通电延时，失电复位；15-16 延时 NC 与 25-28 延时 NO 相互隔离 | 显式 `advance-time` 推进虚拟时钟，逐个处理期限；默认 3000ms 是教学设置，不是图纸参数 |
| 单控/双控 | 单刀单掷/单刀双掷的离散连接关系 | 双控允许直连或交叉联络线，只要求两处均能切换灯状态 |
| 熔断器 | 完整熔芯视为永久导通 | 不模拟熔断。课程通过移除其内部连接检查是否被旁路，并要求控制熔断器位于相线侧 |
| 双极接线端子 | A/B 同极相通，A2/B2 同极相通，两极绝缘 | 增加中间端子不影响正确接线的等效性 |
| 带电导线颜色/动画 | 端子网络含相位来源即视为带电 | 表示电位存在，不表示实际电流方向、大小或功率 |

接触器求稳定状态最多迭代 64 次；状态重复振荡返回 `UNSTABLE_CONTACTOR_LOOP` 并停止教学供电。自断常闭线圈回路不会无限运行。

## 安全与保护规则

| 规则 | 诊断 | 关键行为 |
| --- | --- | --- |
| 不同相经导线/闭合触点直接短接 | `PHASE_SHORT` | 仅在实际闭合路径形成后触发；检查断路器或接触器刚合上的短路 |
| 相线直接短接 N / PE | `PHASE_NEUTRAL_SHORT` / `PHASE_EARTH_SHORT` | 保留短接路径后锁存教学故障 |
| N 与 PE 在训练板内相连 | `NEUTRAL_EARTH_BRIDGE` | 禁止在本教学供电边界内重新合并二者 |
| 线圈/灯将 PE 当返回导体 | `EARTH_AS_RETURN` | 不允许用“PE 与 N 都是零电位”替代工作返回路径 |
| 电机 U/V/W 错接 PE | `MOTOR_EARTH_RETURN` | 绕组端不能替代外壳保护端 |
| 电机没有持续的保护接地路径 | `PE_MISSING` | PE 只可通过导线和固定接线端子；经开关、熔芯、过载通道或线圈端子不算通过。缺 PE 不会虚构“电机无法受电” |
| 标为保护地的端子接入相电 | `EARTH_TERMINAL_LIVE` | 检查所有 `electrical: earth` 端子，包括电机外壳端和 PE 接线端子；不能把 PE 端子当普通相线接线点。故障证据锁存 |
| 标为保护地的端子用作 N 返回 | `EARTH_TERMINAL_NEUTRAL` | 即使该端子暂未连接电源 PE，保护地端子也不能替代普通中性线端子；检查语义属性与实际电位，而非只检测源 N/PE 是否短接 |
| 主回路绕过 QF/KM/FR，控制回路绕过 FU | `PROTECTION_BYPASS` | 分别去除指定器件内部连接，再检查各电机相或线圈供电是否仍可到达 |
| 用 KM 辅助触点代替主触点给电机供电 | `MAIN_CONTACT_BYPASS` | 仅去除 KM 的三组主触点后仍能给电机送电即失败；保留辅助触点路径作证据，允许正确使用不同主极的等效接法 |
| 控制熔断器只串在 N 返回导体 | `FUSE_ON_NEUTRAL` | 可能仍运行，但不满足本课程相线保护要求 |
| 灯的 N 返回经过开关、熔芯或其他器件内部通道 | `SWITCHED_NEUTRAL` | 灯会切换仍不足以通过；N 只可经导线及普通固定接线端子返回，两极普通端子均可使用，不接受 PE 端子作 N 返回 |
| 电机缺相 | `MOTOR_PHASE_MISSING` | 运行层报告缺少独立相位；课程安全检查不能通过，不能只检查指定电机而忽略额外缺相负载 |
| 课程中存在额外电机、灯或线圈 | `LESSON_LOAD_UNCOVERED` | 当前四项课程未定义额外负载的控制与保护目标，返回 `unsupported`；不修改自由运行状态，也不把局部合格当成整份电路合格 |
| 停止、过载、失压恢复等行为错误 | `STOP_INEFFECTIVE` / `OVERLOAD_INEFFECTIVE` / `UNEXPECTED_RESTART` 等 | 返回实际操作结果和可定位元件 |

故障原因与路径保存在 `Runtime.latchedDiagnostics`，按钮释放、分合闸、过载 RESET 都不会抹去首次故障证据。故障复位需要显式 `reset-fault`，复位后电源保持断开，再显式打开教学电源；结束并重新开始仿真也会创建新的空运行状态。没有计算故障电流、保护选择性、断路器动作曲线、熔断时间、漏电保护、电弧、触电或接地阻抗，因此不能用本应用验收实际安装安全。

## 保留的四项课程目标

| 课程 | 配置与操作目标 |
| --- | --- |
| `motor-jog` | 220V 线圈，合闸不自启，按住启动运行，释放立即停；过载 TEST 释放，RESET 后须重新启动；主回路和 PE 完整 |
| `motor-self-hold` | 380V 线圈，启动释放后保持，停止与过载均优先；同时按住启动和停止时停止有效；释放停止、RESET、失压恢复后不自动重启（启动未被按住时） |
| `lighting-single` | 单控开关接相线，开关闭合灯亮、断开灯灭；断路器能隔离相线，N 直接返回 |
| `lighting-two-way` | 遍历两开关四种位置组合，在每种组合中切换任意一只开关都改变灯状态；N 直接返回、相线经过断路器 |

课程角色绑定由 `roles` 指定，缺少绑定时仅在该角色所需类型唯一时推断。当前两种电机课程的线圈电压作为明确教学配置固定，不自动把 220V 课程变成 380V 课程。

固定步骤后还对**电路中所有操作件**探索可达状态，包括用户额外添加的开关/按钮/过载继电器。额外开关后藏着短路，不能由于默认断开而通过。最多 24 种操作事件和 512 个状态；超限报告 `STATE_LIMIT` 与 `unsupported`，不假定未探索部分安全。

`LessonAssessment.trace` 是自动评估的步骤记录：事件、动作、教学电源状态、器件观察值和诊断代码。失败反例的 `Diagnostic.actionSequence` 可以从初始状态重放。它们不是用户手动练习历史，不应作为真实学习时长或熟练度证据。

## 新主目标：十项电机课程

用户提供的十张原理图与十张布局图对应 `motor-course-01` 至 `motor-course-10`；逐图关系、额定控制电源、精确端子映射和动作目标见 [十课契约](./ten-motor-lessons.md)。原四课成绩不能代替新十课成绩。

十图控制回路均用不同的两相，经 FU2a/FU2b 两个熔芯；线号 `0` 不是 N。01 点动原图没有 FR；02 至 10 的保护路径按各图定义，不能用旧课统一的“必须含 FR”判分。07 分别覆盖两台电机、两个 FR 和两套 KM；08 覆盖 KA/KT；09 覆盖 KM/KMY/KM△；10 覆盖 KM1/KM2/KM3 和 Δ/YY 电机。主 FU1 各极、控制 FU2 各导体都以必要路径检查，允许等效端子与器件极序互换。

十课评估在 `motor-course-assessment.ts` 执行代表性动作矩阵、停止/过载/复位、定时边界和路径切断检查，并对互锁触点做必要性验证；**这不等于穷举所有异步接触器物理时序**。额外未声明负载、开关和保护器件返回未覆盖。共享核心 64 次固定点上限继续适用；一次时间推进最多处理 1024 个期限，超限为 `TIME_EVENT_LIMIT`，不能把未推进完成的后半段判为已验证。

一次 `advance-time` 跨越多个期限时，返回的元件状态对应最终时刻，但 `supported` 汇总整个时间窗，错误以及 PE/缺相证据也保留其发生时间。后一个期限恢复正常不能抹去前一个期限的错误接法或缺相。普通 `MOTOR_WINDING_OPEN` 转换间隙不会因此被强制锁停；模型未覆盖与实际故障锁存仍是两种结果。

## 等效接线与未支持范围

接受添加普通接线端子、调整串联停止/过载触点顺序、反转导线端点顺序、使用上/下 A2、交叉双控联络线、调整布局/颜色/绘图路径等电气等效改动。没有用示范图的精确边集合判分。

不求解多电源同步关系，也不求解经悬浮中间网络串联的线圈/灯负载电压分配；这些网络明确返回 `MULTIPLE_SOURCES_UNSUPPORTED` 或 `UNSUPPORTED_LOAD_NETWORK`。六端模型的浮动绕组端若与其他负载耦合，返回 `UNSUPPORTED_MOTOR_LOAD_NETWORK`。PLC、变频器、整流器、非通电延时型继电器、电动机制动、一般 RLC/三相不平衡负载仍未定义。Y/△ 与 Δ/YY 仅实现图内的离散外接模式，不解真实绕组电流或任意电机内部设计。不能将“没有报错”解释成所有物理行为已验证。

## 验证

自动测试位于 `tests/simulator-engine.test.mjs`，直接打包浏览器/服务器使用的同一核心及几何模块。覆盖四课程、按钮释放、自锁/停止优先、过载旁路、闭合后短路、额定线圈类别、PE/N、缺相/反向、振荡、串联负载、等效接线、额外控制隐藏危险、可重放反例、SVG 原图端子圆心、端点移动/重载和导线样式独立性。

运行：`node --test tests/simulator-engine.test.mjs`。浏览器仍须完成实际拖线与操作验收；纯核心测试不能替代画布指针事件验收。

## 规则参考

这里区分产品教学约束与制造商资料，不宣称实现全部法规或某个真实器件型号。

- Schneider 的 [保护接地连接说明](https://www.electrical-installation.org/enwiki/Connection_and_choice_for_protective_earthing_conductor) 要求 PE 保持连续，并说明分离后的 PE/N 不应在下游重新连接；本模型将其落实为独立 PE 网络和受限固定连接路径。
- Schneider 的 [过载手动复位说明](https://productinfo.se.com/tesysgigainstallationguide/tesys-giga-series-giga-contactors-and-giga-thermal-overload-relays-installation-guide/English/TeSys%E2%84%A2%20Giga%20Series%20Giga%20Contactors%20and%20Giga%20Thermal%20Overload%20Relays%20Installation%20Guide_0000447511.xml/%24/PanGu_TripResetCPT_0000524825) 给出锁存与 95/96、97/98 复位变化；[TEST FAQ](https://www.se.com/us/en/faqs/FA102153/) 说明正确控制接线中的 TEST 应使电机停止。
- Schneider 的 [中性线保护](https://www.electrical-installation.org/enwiki/Protection_of_the_neutral_conductor) 与 [中性线隔离](https://www.electrical-installation.org/enwiki/Isolation_of_the_neutral_conductor) 说明实际设计取决于系统类型、截面和上游保护。当前课程限定单极控制熔断器在相线、灯 N 直接返回；不把该局部规则泛化成“任何系统都不能保护或切换中性线”。
