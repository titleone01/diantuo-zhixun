# 个人中心对照与分页验收（2026-09-30）

## 对照依据

源站 `/user` 的公开前端及其引用脚本 `/_next/static/chunks/app/(playGround)/user/page-3772f84316a66521.js`（模块76405）。这是静态前端取证，不能代替源站同视口的实际交互验收。

- 默认“我的电路”，随后“草稿箱”“收藏图纸”；桌面侧栏366px，外边距与间距16px，页签高48px。
- 草稿表包含标题、更新时间、操作，默认10条，可选20/25/30/40/50条；源站先取列表再本地分页。
- 我的电路、收藏为预览列表，1280px一列、1536px以上两列，预览240×140。源站使用虚拟滚动，部分请求固定100条。
- 源站还有公开/私有筛选、排序、作品下架和收藏批量取消等入口。

## 本地实现

- 草稿由服务端按所有者分页，支持标题筛选，稳定按更新时间和ID降序排列；返回总数和有效页码，不再截断为前200条。客户端默认10条。
- 我的电路和收藏每批12条，滚动追加，预览随列表一次返回，不逐卡请求。使用内容可见性优化，未宣称采用与源站相同的虚拟列表实现。
- 账号、页签、搜索或刷新变化后拒绝旧请求结果；重复滚动回调不重复推进页码。加载失败保留已有项并允许重试；数据缩减导致页码夹取时重新加载首批。
- 私有草稿删除沿用修订校验和确认框；删除当前已保存草稿时保留工作区为未保存副本。发布快照独立于草稿。
