# 二维仿真主产品

2026-09-30 用户批准切换到二维整站。随后明确要求器件和图纸直接参照原站现有素材，不采用新生成的器件插图。本文件优先描述新主产品；旧三维规则继续适用于 `app/training/` 历史代码。

## 实现边界

- 主入口 `app/page.tsx` → `app/simulator/SimulatorApp.tsx`。模拟电路、图纸集、仿真广场、元器件百科、个人中心共享账号会话。
- 编辑器 `app/simulator/editor/` 使用 React Flow 自定义器件与端子。保存器件世界位置和稳定端子 ID；显示坐标从位置加局部端子坐标计算。导线交叉没有电气连接意义，分支必须接到同一端子。
- `app/simulator/core/catalog.ts` 定义器件图幅、端子、电气属性、内部桥接、触点和额定电压。原站素材为通用教学图，不作为具体厂商真实尺寸模型的证据。
- `engine.ts` 是共享纯引擎：运行、安全诊断、课程检查分开。客户端预览；`/api/assess` 在服务端重新计算，不相信客户端传来的通过结果。
- 当前 `LESSONS` 有 14 个课程定义：按用户正式图纸实现的 10 个主要电机课程，以及保留的点动、自锁启停、单控照明、双控照明 4 个基础课程。十课模板位于 `core/motor-courses.ts`，判定由共享引擎及相应课程检查模块执行；具体浏览器验收结果另见验收记录。
- `CATALOG` 有 29 种可放置对象，其中 27 种有电气端子，包含 KA、KT、SQ、双联/三联熔断器、16位端子排、刀开关、保持型按钮、关联常开辅助触点和两类六端电机；另有横向、纵向 2 种无端子线槽。PLC 未开放。目录外的控制、负载或图纸不自动获得仿真支持。
- 课程检查在副本上运行。自动课程动作 trace 不等于学员真实操作记录。未选课程返回“未指定课程/不作课程判定”，不能宣布“接线正确”。

## 参考站资料与复现边界

参考站：<https://elesim.jcpeixun.com/>；审查例子：<https://elesim.jcpeixun.com/shared-circuit/detail/524>。

已观察原站栏目、图纸分组、元件池、拖线形态、个人资料界面，以及公开客户端的 WebSocket 消息格式。原站把端子连接关系交给后台计算；浏览器曾停留在“连接中”，2026-09-30后续通过正常登录与WebSocket完成示例524五阶段实测，并与本地等效拓扑逐项一致，见 `reference-runtime-524.md`。这里独立实现并测试电气规则，不声称获得或复制了不可见的原站后台源码，也不将单个用例扩大为全站行为一致。

用户要求复用原图后，本地 `public/sim-assets/` 保留 23 个原始器件 SVG（其中部分为教学扩展的图形来源）与 18 张原站图纸。另有用户提供的 20 张正式项目 PNG，存入需登录读取的本地 R2；不作为公开静态素材。生成器件插图没有纳入网站。资源来源与裁剪、缩放、教学改型见 `reference-assets.md`。主界面保留原站白色导航、蓝色操作按钮、浅灰点阵画布、左侧三列器件池、彩色导线、右侧浮动原理图；品牌、账号、草稿、成员共享和后台独立。

参考图并不自动等于安全标准答案。图纸集明确标记当前可运行课程；点动图的额外 PE/过载检查、照明图中只开放单控子回路均有说明。原站图中没有交互 PE 的电机，本地按图中实际接地端补充可接线 PE，不把缺 PE 当作合格。

原基础点动课程保留其额外过载检查；正式 `motor-course-01` 按用户点动图使用 380V 控制回路和两路 FU2，不凭空加入图上没有的 FR。各课按自己的目标和保护元件判定，不能把另一课程的示例通过结果代用。

KT 原图左瞬时/右延时标识与本地双延时教学定义不同；KA 的 380V 额定值和双速电机 Δ/YY 绕组也属于明确标注的本地教学定义。源站六端子星三角电机外观确已找到，但未发现独立双速型号。任何这些外观复用都不证明原站后台采用同一模型。

## 编辑与电气行为

导线支持直角折点、直线和曲线，默认取起点端子颜色，连接后可独立改色。颜色、折点和交叉只影响显示；引擎按稳定端子 ID、固定内部连接和当前闭合触点建立电气网络。线圈、电机等负载不按导线短接合并。

复合按钮与 SQ 在离散动作中先断后合，按住/释放改变实际触点。KM/KA 随线圈得电动作；关联常开辅助触点由 `linkedTo` 指向 KM/KA，未关联可以保存草稿，但仿真明确报告暂不支持。KT 使用 `settings.delayMs` 和独立逻辑时钟，支持自动推进、暂停和手动步进；失电复位。电机显示实际判定的正反转、星形/三角形/双星形和高低速状态，未计算真实转速。

六端电机只识别当前定义的外接绕组模式；多电源域、串联负载电压分配、浮动绕组端与其他负载耦合等超出模型的网络明确报告暂不支持。不支持与故障锁存分开显示：不支持时保留实际可计算的受电状态并暂停自动计时，不用强制停机掩盖错误接线。短路等危险故障中止教学电源并保存首次故障路径，普通按钮释放或过载复位不会清除，须明确复位故障。

热继电器 TEST 只改变保护触点，电机是否停止由接线决定；保护被旁路不能靠强制停止电机通过检查。课程检查还验证目标动作、失压恢复及保护动作；自由接线没有课程合格结论。当前实现是离散教学仿真，不计算实际电流、电磁、热、机械瞬态或设备安装精度。

线槽可放置、移动、独立调整长宽、删除、撤销与保存恢复，深灰槽体位于器件和导线后面；没有端子、负载或电气导通。选中后的尺寸手柄使用二维世界单位，长宽均限制在 24–4000；一次拖动作为一次撤销，运行和只读状态禁止调整。画布节点、取景和接线快照统一读取实例尺寸。

编辑器默认“自动走线槽”，新自动线规范保存 `style:"orthogonal", routing:"duct"`；手工直角、直线、曲线独立可选，原有waypoints保留以便切回手工。共享 `core/duct-routing.ts` 从世界坐标端子沿12单位定向出口离开本体，按真实矩形槽的连通网络寻找路径，避开全板器件本体，按稳定wire.id作有限平行偏移，并再次验证每段覆盖。移动/尺寸/重载重新计算。`editor/duct-routing.ts` 是兼容适配器；编辑器、线头与作品预览共用geometry路径。缺槽、遮挡或断槽自动线保留电气from/to，只显示两端分开的引线及持续可见提示，不画跨板飞线。旧保存 `style:"duct"` 在非突变校验中归一化为规范格式，直接渲染也兼容。该算法为教学示意，不作线径容量或真实安装合规判定。

新接线选择“直线”时，若画布已有线槽，也记录 `style:"straight", routing:"duct"` 并共用上述自动路由；没有线槽时保留普通直线。旧文档缺少 routing 的直线保持原状，明确修改已有导线为手工样式会清除自动路由标志、保留原折点。

正式十课通过 `core/motor-practice-layout.ts` 建立独立的新练习，预排器件、双联 FU2、16位 XT 和六段线槽，初始无导线；可移动、删除及从器件库添加。双联熔断器的两路独立；XT 的32个端子按16对上下相通、位间绝缘。旧双单极 FU2 文档继续由同一评分契约接受。布局与派生SVG均为教学示意，原始素材保留。

编辑剪贴板支持单个及整组选中对象，保留设置、尺寸和两端均在组内的导线，重建实例ID/位号及组内辅助关联，清除并提示组外关联；不继承课程角色和运行状态。一次粘贴偏移32世界单位并对应一次撤销，账号会话变化清空剪贴板。切换课程或新建前将未保存内容写入账号独立的本机暂存并回读；失败保留画布，成功后可从“课程与草稿→本机暂存”恢复。

## 状态与数据

新文档 `schemaVersion:1`，保存 `components`、`wires`、可选 `lessonId`、课程角色映射、图纸媒体 ID。组件实例可保存辅助触点 `linkedTo`、KT `settings.delayMs` 和线槽的可选 `size: {width, height}`；资产定义仍在目录中。旧线槽文档缺少 `size` 时使用资产默认尺寸，其他器件不接受此字段。每根线保存端子引用、颜色、线形、可选折点及可选 routing 字段。不存 DOM 像素作为电气端点。

2026-10-02 的聊天反馈改动中，普通端子和 PE 端子资产尺寸及所有局部端子坐标统一缩至原来的 75%，稳定端子 ID 和内部导通关系保持不变。可见线头沿同一世界路径投影到端子附近，避免被原图遮挡。导线采用 3px/选中 4px、不随画布缩放变细的显示宽度；已有颜色按文档保存值显示。接触器使用原 SVG 派生的状态区域，保留原始资源和一套印刷端子标号；中间色块在吸合时变红并显示白色「吸合」。各可接线端子的中心黑点由实际 `TerminalState.energized` 驱动，运行带电时为红色，N/PE 不按线色推断。

短路警告窗口只读取当前仿真会话的锁存短路诊断，使用会话代数和故障通路去重。确认或定位只改变窗口/画布呈现，不调用复位电源；结束仿真后才可修改接线。课程判定副本中的诊断不触发当前画布警告。图纸浮窗的移动、调整窗口大小和页内全屏属于呈现状态，不保存到电路文档；50%–400% 缩放仅作用于图片、PDF 或内联原理图，可滚动及拖看。切换到个人上传图纸会清除此前浏览的项目图纸上下文。

`projectDrawings` 保存原理图/布置图两份媒体 ID 和类型，`drawingKind` 标记当前显示图，`drawingMediaId` / `drawingMediaType` 支持当前预览及旧单图文档。即使布置图页签未打开，其媒体引用也必须接受服务端权限检查并随作品保存。个人上传单图会清除项目双图关联。PNG/JPEG/WebP 使用图片预览，PDF 使用本地 PDF.js Canvas 与多页控制，不依赖浏览器 PDF 插件。

运行时冻结器件、导线、课程切换和元件属性编辑，通过开关、按钮、限位、计时和 TEST/RESET 操作独立 runtime。停止仿真不把运行中的触点状态写进接线文档。接触器从上一次稳定状态开始迭代；每轮检查短路，限制振荡和迭代次数。课程检查异步返回时须核对文档快照，防止旧图的通过结果落到新图上。

新 localStorage 命名空间为 `diantuo:simulator:*`，按账号隔离临时恢复状态。恢复记录损坏时不自动载入；后续写入前将原始内容保存在该键下的 `:unreadable:<随机ID>` 备份，备份失败则保留原记录并报告。旧三维 localStorage、GLB、原始模型、未提交修改均保留；不自动迁移或转换旧存档。

2026-10-03 增量修复：JSON 文件异步读取使用文档引用、仿真代数和文件请求顺序保护，迟到结果不能覆盖后来编辑或运行的工作区；课程 08/09 的一小时最大延时验证拆为合法时间步；预览包围盒逐点累计，避免合法大文档触发函数参数栈溢出。API 请求含 30 秒超时和对象响应校验，不自动重试写操作；超时不能证明服务器未保存，须回读确认。

账号使用 Better Auth，D1 存用户/会话/邀请/草稿/发布/反应/课程记录，R2 存附件。注册需一次性可过期邀请，服务器检查管理员与所有者。草稿修订号采用原子比较更新，冲突不静默覆盖；发布记录为独立快照。私有附件在发布或管理员关联到项目图纸之前不能被其他成员读取。

## 运行与构建

本地完整入口通过 `worker/local.ts` 使用同一 API/D1/R2 与实际 React 主站，监听 `http://localhost:3000/`。主站本地构建不启用静态演示开关。由于当前 Windows 环境的 vinext 开发优化过程出现资源占用问题，交付默认使用直接 Worker 入口；各构建与浏览器运行的实际结果以验收记录为准。

`npm run build:pages` 将 `__STATIC_DEMO__` 固定为 true，只生成静态演示。演示草稿仅存在当前浏览器，不存在假的成员后台或公开私人数据。`docs/` 仍然只存构建产物。

测试与启动见 `local-runbook.md`、`electrical-rules.md`、`acceptance-2026-09-30.md`。
