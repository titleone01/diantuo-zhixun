# 第一版三相电机直接启动训练规格

## 已确认目标

第一版完成一个完整的三相电机直接启动（DOL）训练闭环。学习者必须能够在同一三维接线板中完成真实器件放置、主回路接线、控制回路接线、线槽整理、合闸、启动、停止和故障复位，并看到器件状态与电机状态一致变化。

## 最小器件集合

- `QF1`：三极小型断路器，候选型号 CHINT NXB-63 3P；
- `KM1`：三极交流接触器，候选型号 CHINT NC1-0910；
- `FR1`：与 NC1-09 接插匹配的过载继电器，候选型号 CHINT NRE8-25；
- `SB1`：停止按钮，常闭触点；
- `SB2`：启动按钮，常开触点；
- `X1`：三相进线与控制电源所需的 TH35 导轨端子；
- `X2`：电机 U/V/W/PE 出线所需的 TH35 导轨端子；
- `PE`：与 DIN 导轨/安装板形成明确保护导体连接的专用 PE 端子；
- `M1`：三相电机或具有 U/V/W/PE 真实端子的电机接口及运行反馈。

TB-1506 是安装板螺钉固定的屏障式端子排，不作为上述 TH35 导轨端子的替代品。

## 官方型号证据

- 正泰 NC1 官方资料列出 NC1-09 与 NRE8-25 的匹配组合；
- NRE8-25 可与对应 NC1 接触器接插安装，并有官方 STEP 和尺寸图；
- NP2 系列用于接触器、继电器等工业控制回路，并有官方 STEP；
- JXB/JCUK 系列官方注明采用 TH35 导轨安装。

第一版电机参数已确认为三相 380V、2.2kW。按正泰 DOL 配套资料，该功率档可用约 4.9A 作为选型参考，NRE8-25 选择 4–8A 整定范围；训练中的最终整定值仍应读取并匹配 M1 铭牌额定电流，不能把参考电流当成所有 2.2kW 电机的固定值。

NC1 接触器线圈已确认为 380V，控制回路采用断路器负载侧两相之间的 380V 线电压，不设置 220V 控制变压器。在正式入库前，每个具体子型号仍必须补齐颜色、触点组合、整定电流、尺寸、安装方向和端子坐标。

## 主回路

主回路固定按以下功能顺序设计：

`X1(L1/L2/L3) → QF1(1/3/5) → QF1(2/4/6) → KM1(1/L1、3/L2、5/L3) → KM1(2/T1、4/T2、6/T3) → FR1 → X2(U/V/W) → M1(U/V/W)`

`X1(PE) → PE 专用端子/保护导体路径 → X2(PE) → M1(PE)`

主回路端子编号最终以各具体型号官方图纸为准。导线必须从端子短距离进入相邻线槽，长距离仅在线槽网络内运行。

## 控制回路

控制回路必须包含：

- QF1 已合闸作为启动许可；
- SB1 常闭停止触点；
- FR1 常闭保护触点 `95-96`；
- SB2 常开启动触点；
- KM1 线圈 `A1-A2`；
- KM1 常开辅助触点 `13-14` 与 SB2 并联形成自锁。

控制电源已确认为 380V，第一版固定从 QF1 负载侧 `L1-L2` 两相取电，标准控制路径为：

`QF1(2/T1) → SB1(11-12，常闭) → FR1(95-96，常闭) → [SB2(13-14，常开) ∥ KM1(13-14，常开自锁)] → KM1(A1) → KM1(A2) → QF1(4/T2)`

只有具体 NC1 子型号铭牌明确标注 380V 线圈后才能作为正式训练资产；不能仅靠外形模型推断线圈电压。

## 状态闭环

1. QF1 断开时，控制回路无启动许可，KM1 和 M1 必须释放/停止。
2. QF1 合闸且接线正确时，按下 SB2 使 KM1 吸合；KM1 主触点与辅助自锁触点同步闭合，M1 进入运行状态。
3. 松开 SB2 后，若 KM1 的 `13-14` 自锁支路正确，KM1 和 M1 保持运行。
4. 按下 SB1，控制回路断开，KM1 释放，主触点断开，M1 停止。
5. FR1 动作时，其 `95-96` 断开，KM1 与 M1 停止；完成复位前不得再次启动。
6. 缺线、接错线或未形成自锁时，表现必须符合实际拓扑，不得为了演示效果强制进入运行状态。

## NRE8 过载动作与复位依据

- 正泰 NRE8 官方说明书 Figure 11 标明了测试功能和手动/自动复位选择；测试位置使 `95-96` 转换到 `97-98`。
- 官方说明书 Figure 12 标明独立 `RESET` 按钮，故第一版提供“教学过载测试”和“FR1 RESET”运行控制。
- 当前 GLB 尚未完成测试旋钮与 RESET 原件的运动学标定，因此只改变电气触点和状态反馈，不在三维模型表面添加主观绘制的可动件。

## 第一版验收

- 所有器件型号、尺寸、安装方式、方向和端子坐标通过官方资料标定门禁；
- 按统一毫米比例呈现安装板、DIN 35 mm 导轨、线槽及全部器件；
- 主回路和控制回路都能从真实螺钉/触点拖线完成；
- 正确接线可以完成合闸、点动、自锁、停止、过载跳开和复位；
- 错误或不完整接线不能误判为运行；危险短接继续由独立拓扑安全模块拦截；
- 浏览器中完成至少一遍从空板到电机运行再停止的人工验收，并核对每根导线端点世界坐标与端子世界坐标一致。

## 待确认参数

- NP2 启动/停止按钮的具体外形、颜色和触点模块子型号；
- M1 在接线板内显示完整电机模型，还是只显示外部电机接口并在侧边显示运行反馈。
