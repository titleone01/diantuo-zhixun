# 原站选图与本地工作区

2026-09-30。范围是原站 18 张参考原理图的选择、配置入口、视频关联与保存；不将 18 张图等同于 18 门已验收课程。

## 已核对的源站契约

依据公开页面脚本 `blueprint/page-d9735c6784448d92.js` 模块 83947、`circuit/page-078a7277d0e02693.js`、公共块 `3707-57a08fe2bcde9a7d.js` 模块 53707 和 `6765-d566129f5ae05f9a.js` 模块 22611。本轮为静态调用链核对，不冒充源站浏览器操作实测。

- 图纸集进入 `/circuit?diagram=<id>`，所有图共用配置页。初始放置七个未接线器件：电源、三极刀开关、三联熔断器、380 V 接触器、三相电机、单极熔断器、红色复合复位按钮。
- 查询参数只为浮窗选择图名、图片和视频，不按图装载示范连线。
- 浮窗左下按钮打开“图纸选择”：三列、每页九张、单选、名称搜索、分页、取消和确认；不提供类别/难度筛选，点击遮罩不关闭。
- 确认只切参考图及其视频，保留当前器件、连线和页签。源站选图不写 URL，刷新回到 URL 指定参考图。

## 本地实现与必要差异

公共目录位于 `app/simulator/core/reference-drawings.ts`；文档保存 `referenceDiagramId`，格式仍兼容已有 v1 文档。图名、图片路径及视频通过白名单 ID 查询，不保存任意远端 URL。

图纸集 18 张均可进入未接线配置。四个旧课程另提供“查看示范接线”；其他原图不会因此获得自动课程判定。选另一个参考图保留标题、器件和导线，清除此前课程/角色与私有附件关联，可撤销；选择当前同一张图不改电气文档，但退出正在预览的其他正式项目。

原站没有保存当前选图的行为被本地草稿持久化替代：保存、发布独立快照、复制及 JSON 往返均保留参考 ID。`/circuit?diagram=<id>` 也可作为一次入口请求；完成账号恢复后才处理。相同 ID 保留已有接线，未保存的其他接线先走已有替换确认，无效/重复参数不改文档。处理后移除入口参数，刷新按本账号恢复记录继续，不重放新建。

参考 ID 与正式项目/私图附件字段互斥。切到参考图时清除草稿的附件关联，但不删除 R2 原文件。旧客户端省略 `mediaIds` 也不会继承前一张私图；发布拒绝混合附件。正在上传图纸时若用户已换图、编辑、切工作区或启停仿真，迟到的上传结果不会覆盖当前选择。

运行期间锁定换图与接线编辑；仍可查看已选图的视频。视频始终对应当前参考 ID；正式项目或私图预览不沿用旧课程视频。源站视频仍需网络。

七器件的初始世界位置取源站 desktop 初始化值；本地端子位置以实际原 SVG 圆心为准，不把旧脚本与素材不匹配的端口偏移当电气事实。浏览器画布缩放是显示变换，不写进电气端点。
