## 逐课电气关系与动作验收

### 01 点动

- 主回路：QF → FU1 三极 → KM 三组主触点 → M；**原图没有 FR**。
- 控制：FU2a → SB NO → KM 线圈 → FU2b；两个 FU2 分别在不同相导体。
- 合闸不自行启动；按 SB 运行、松 SB 停止；断 QF 或任一控制导体断路均释放。重新合闸且 SB 未按住时不启动。
- 不把“缺 FR”判作该图未完成；也不声称此简化点动教学图满足所有实际电机保护设计要求。旧 `motor-jog` 的 220V/N/FR 目标不适用于本课。

### 02 连续运行

- 主回路：QF → FU1 → KM → FR 主检测通道 → M。
- 控制：FU2a → FR NC → SB1 NC → (SB2 NO || KM NO) → KM → FU2b。
- SB2 按下后释放仍运行；SB1 停止且释放后不重启；FR TEST 停止，RESET 不自行重启；失压后恢复且无启动请求时不重启；停止和启动同时保持时停止优先。

### 03 点动与连续运行

- 主回路同 02。FR NC、SB1 NC 后分为三支：SB2 NO；SB3 NO；SB3 NC + KM NO，三支并联后到 KM。
- SB2 为连续启动；SB3 是机械联动的复合点动按钮。SB3 的 NO/NC 不是两个互不相关按钮。
- 必验：SB2 按放自锁；从停止按住 SB3 运行、松开停止；连续运行中按住再松开 SB3 后停止；SB1 和 FR 对两种模式均有效。
- 当前“同时翻转 NO/NC 然后一次固定点”的算法会在 SB3 释放时利用上一步 KM NO 状态重新自锁，产生假通过。新增通用触点过渡：先断开离开状态中的闭合触点，求稳定，再闭合目标状态中的触点并求稳定。此为明确的离散先断后合教学假设，未声称模拟实际接触器释放时间或所有按钮的机械行程。

### 04 接触器互锁正反转

- 两组 KM 主触点分别提供正相序与交换两相后的反相序，共用 FR、M。
- 公共控制链 FR NC + SB3 NC；正向支路 `(SB1 NO || KM1 NO) + KM2 NC → KM1`；反向支路 `(SB2 NO || KM2 NO) + KM1 NC → KM2`。
- KM1 运行时按 SB2 不得直接转为 KM2；先 SB3 停止，后 SB2 可反向运行。反向到正向对称。
- 原图没有复合按钮交叉 NC，不得悄悄加入 05 的功能。也不得硬编码两个 KM 永不同时吸合来掩盖互锁错接。完全同时发出的启动命令涉及实际吸合时序；本模型按可重放操作事件排序，不能据此承诺真实机械互锁性能。

### 05 双重联锁正反转

- 主回路同 04；正向支路增加 SB2 NC，反向支路增加 SB1 NC；SB1/SB2 的 NO 和交叉 NC 各属同一复合按钮。
- 正向运行按反向按钮，应先释放 KM1，再吸合 KM2，松开后反向保持；反向到正向对称。SB3/FR 优先，两方向按钮同时保持时两方向均不可得电。
- 验收应同时观察主回路方向和两 KM 状态，检查操作过渡没有相间直接短接。主触点交叉关系错误或辅助触点被旁路不能因按钮动画正确而通过。

### 06 自动往返

- 主回路同正反转，共用 FR。
- 正向：`(SB1 NO || KM1 NO || SQ2 NO) + SQ1 NC + SQ3 NC + KM2 NC → KM1`。
- 反向：`(SB2 NO || KM2 NO || SQ1 NO) + SQ2 NC + SQ4 NC + KM1 NC → KM2`。公共链 FR NC + SB3 NC。
- SQ1/SQ2 各有联动 NO/NC：触及 SQ1 结束正向并启动反向，SQ2 对称。SQ3/SQ4 是对应方向的越程 NC：SQ3 禁止 KM1，SQ4 禁止 KM2；不能强制任一 SQ 都令所有方向停机。
- 最小电气验收：启动正向 → 触发 SQ1 自动反向 → 释放 SQ1 仍反向 → 触发 SQ2 自动正向 → 释放 SQ2 保持；两端对称，SQ3/SQ4、停止及 FR 均有反例测试。
- 运行内核接受真实 `press/release` 限位事件。若产品展示自动移动工作台，另设确定性的教学行程模型产生 SQ 事件，移动只能由求解出的电机方向驱动；不得用动画直接改变 KM。行程长度和速度图中未给出，应标为演示设置。仅有手动限位按钮时应写“限位触发仿真”，不可声称已完成自动机械往返展示。

### 07 顺序控制

- 一个 QF/FU1，两个分支 `KM1 → FR1 → M1`、`KM2 → FR2 → M2`；两电机都有 PE。
- 控制公共链 FR1 NC + FR2 NC。M1 支路 `(SB1 NC || KM2 NO) + (SB3 NO || KM1 NO) → KM1`。M2 支路 `SB2 NC + (SB4 NO || KM2 NO) + KM1 NO → KM2`。
- 启动必须先 M1 后 M2；M1 未开时 SB4 不得启动 M2。两机运行时按 SB1 不能停止 M1；须先 SB2 停 M2，再 SB1 停 M1。**这是顺序启动加逆序停止，不是只验启动顺序。**
- 任一 FR 动作通过公共控制链停止两机。KM1、KM2 各需要两组电气隔离的 NO 辅助触点：自锁和联锁各一组。不可把同一个 13/14 螺丝用于图中两组独立触点。

### 08 延时起动

- 主回路同 02；公共控制链 FR NC + SB2 NC。
- 预启动支路 `(SB1 NO || KA NO) + KM NC → KA 与 KT 线圈并联`；运行支路 `(KT 延时 NO || KM NO) → KM`。
- 按放 SB1 后 KA 自锁、KT 计时，KM/M 暂停；到时 KT NO 合使 KM 吸合，KM NO 自锁。KM NC 随之切断 KA/KT，KT 失电复位，但 KM 仍运行。
- 计时中停止/FR/断电须取消计时；恢复后不能沿用旧期限自行启动；已运行时仍正常停止。必须检查 KA 和 KT 最终释放，不能做成永远通电的简化延时自锁图。

### 09 Y-△ 降压起动

- 主回路：QF → FU1 → KM → FR → U1/V1/W1。KMY 将 U2/V2/W2 相连；KM△ 闭合时配对为 **U1-W2、V1-U2、W1-V2**，已逐段核对交叉线，不能按画面列序直接一一连接。
- 控制公共链 FR NC + SB2 NC + `(SB1 NO || KM NO)`；KM 持续保持。其后 `KM△ NC` 供 KT 和 `KT 延时 NC → KMY`；另一支 `KMY NC + (KT 延时 NO || KM△ NO) → KM△`。
- 启动进入 KM+KMY，KT 计时；到时先断 KMY，再接 KM△；KM△ NO 自锁后 KM△ NC 使 KT 失电复位。停止、FR、失压均清除运行与计时，重新启动重新计时。
- KT 的 NC/NO 在不同控制支路，必须是隔离触点，不能使用只有一个公共端的单组换接触点。
- 电机定义是三组独立绕组 U1-U2、V1-V2、W1-W2。Y 模式有浮动公共点；该公共点不得连接 N/PE。△ 是闭合三角负载网络，不是三相之间直接的导体短路。每个绕组都必须实际参与，零电压绕组、缺相和错误并接不得判运行正确。
- 只识别教学拓扑及转换顺序，不计算真实启动电流、转矩、切换空档毫秒数或选型整定。380V 电源下采用适合该线电压 △ 运行的示意电机，不宣称任意六端电机都适用。[Schneider 六端与额定运行条件](https://eshop.se.com/in/blog/post/star-delta-starter.html)

### 10 双速 Δ/YY

- 原图电机符号明确为 Δ/YY，六端但**不是 09 的独立三绕组**。QF → FU1 → FR 后分支；KM1 供 U1/V1/W1；KM2 供 U2/V2/W2；KM3 共接 U1/V1/W1。
- 图中 KM2 输入从左至右是 L3/L2/L1；输出又经不同长度回线从左至右到 W2/V2/U2。所以最终仍为 **U2=L1、V2=L2、W2=L3**，与低速端序一致。只看接触器横排会误判高低速反向。
- 公共控制链 FR NC + SB1 NC；低速 `(SB2 NO || KM1 NO) + SB3 NC + KM2 NC → KM1`；高速 `(SB3 NO || KM2 NO) + SB2 NC + KM1 NC → KM2 与 KM3 线圈并联`。
- 低速：仅 KM1，U1/V1/W1 受三相电，另一组三端没有外接供电或短接。高速：KM2+KM3，U2/V2/W2 受三相电，U1/V1/W1 为隔离的公共连接；两模式正确自锁并可通过复合按钮切换。
- 必验高速时 KM3 缺失/错接、KM2 或 KM3 缺相、低高速重叠、两组相序不一致、停止/FR/失压。不能只根据 KM1/KM2 布尔状态显示“低速/高速”。
- 厂商通用图核验：ABB《Motor Guide》2019 第 56 页图 4.6/4.7 将普通三相 Y/△、双绕组双速和单绕组 Dahlander Δ/YY 分开；Δ/YY 的低速接第一组三端，高速接第二组三端且短接第一组。新模型按这套外部端子模式识别，不虚构其内部为三组独立线圈。[ABB 原始手册](https://library.e.abb.com/public/1fd380f8ca8b4934ae3fa609d764fd33/21043_ABB_Motor_Guide_REV_D.pdf)

## 共享核心接口（新增，保持旧文档兼容）

`schemaVersion: 1`、导线端子引用、绘图路径和旧元件类型保留。新增实例可选字段 `linkedTo?: string`（辅助块机械关联）与 `settings?: { delayMs: number }`（KT 设置）。未知/非法设置须由客户端和服务端同一个 `validateDocument` 拒绝；不把所有任意 JSON 参数透传给运行内核。

| 新类型 | 稳定端子 ID | 电气语义 |
| --- | --- | --- |
| `auxiliary-no` | `13,14` | 独立 NO，实例 `linkedTo` 指定 KM/KA；缺绑定不可假装正常 |
| `relay380` | `A1,A2,13,14,21,22` | 380V KA；NO/NC 跟随线圈，无电机主触点 |
| `timer380` | `A1,A2,15,16,25,28` | 380V 通电延时；15-16 延时 NC、25-28 延时 NO，两组无内部导通 |
| `limit-switch` | `11,12,23,24` | SQ 联动 NC/NO，接受按下/释放；一课可只用 NC |
| `motor-star-delta` | `U1,V1,W1,U2,V2,W2,PE` | 三组独立绕组；辨别 Y/△ 端子网络 |
| `motor-dahlander` | 同上 | Δ/YY 外接模式；辨别低/高速，独立于 Y/△ 模型 |

端子数字为教学模型 ID，实物针脚尚无型号证据时不得宣称具体厂家型号；素材与螺丝坐标由器件校准任务单独确认。源站只找到普通六端电机图，不把它误称源站已提供双速电机模型。

- `initialRuntime(document,powerOn=true)` 和 `simulate(document,runtime,action)` 保持调用方式。
- `SimulationAction` 新增 `{type:'advance-time',ms:number}`；时间只从显式事件推进，核心不调用系统时钟。参数须有限、非负并有上限。
- `Runtime` 增加 `timeMs`、`timers[id] = {energized,startedAt:number|null,elapsedMs,done}`。延时默认 3000ms、允许设置；这是产品演示默认值，原图没有给出秒数。
- KT 连续得电开始计时，失电立即清零。到期前/到期边界/到期后分别求解。跨越多个期限的时间推进要顺序处理期限，不能只把最终时间写入后算一次；按钮、停止、故障与时间事件均可重放。普通 NO/NC 不因 KT 存在而都变成定时触点。[Schneider 通电延时复位](https://www.se.com/us/en/faqs/FA124951/)、[普通与定时触点区分](https://www.se.com/ca/en/faqs/FA107844/)
- `ComponentRuntime` 继续使用 `active/state/direction`，新增 `connection:'star'|'delta'|'double-star'`、`speed:'low'|'high'`；KT 显示等待/计时/到时并提供剩余时间。输出来源是端子网络，不是课程名称或图片。
- `load.kind` 仍分 coil/lamp/motor，电机额外通过 `motorModel` 区分三端、Y/△、Dahlander；所有通用 PE、额外负载覆盖和安全检查按 load 类型收集，不能仅检查 `component.type==='motor'`。
- 导出 `buildCircuitNetwork(document,runtime,options)` 给课程保护路径检查；提供 `connected(a,b)`、`potentials(id)`、`path(a,b)`。端子键为 `componentId::terminalId`，路径保留 wireId/componentId/contactId。options 可单独排除器件或仅排除 KM 主触点，确保辅助触点不能代替主触点蒙混过关。

## 评估模块与测试门槛

课程模板由 `motor-courses.ts` 提供，十课 ID 独立；`motor-course-assessment.ts` 执行动作和保护路径检查；`engine.ts` 保持可脱离课程运行。所有 coil（包括 KA/KT）、每台 M、每组主接触器和保护器都必须在该课角色清单中被覆盖。多电机课不能沿用旧“一台电机、一个线圈”的覆盖集合，也不能全局删除覆盖检查放行额外负载。

共同验收：正确模板；完全等效的普通端子中转/导线反向/布局变化；错电压；缺 PE 与 PE 带相电；主路缺相；QF/FU1/FU2/按图要求 FR 的旁路；KM 辅助触点替代主触点；闭合动作才出现的短路；停止/故障原因锁存；所有课程声明负载以外的附加负载明确未覆盖。FU1/FU2 分别检查每个导体的保护路径，不仅检查“场景中存在熔断器”。

新增有意义反例：03 释放 SB3 假自锁；04 强行直接换向；05 缺交叉 NC、同时按方向键；06 SQ1/SQ2 NO-NC 分拆或接反、SQ3/SQ4 失效；07 缺启动联锁、缺逆序停止旁路、两个辅助触点误合并、任一 FR 无法停两机；08 计时未到提前运行、取消后沿用旧定时、KM 上电后 KA/KT 未释放；09 星三角重叠、只有端子图无绕组闭合、转换不复位、浮动星点接 N/PE；10 缺公共短接却显示高速、六端错用三独立绕组算法、高低档相序不同。

定时必须测 `T-1`、`T`、`T+1`、分段推进与一次推进等价、失电重新计时、停止和到期边界次序。复合按钮要检查中间态诊断而非只看最终电机停止。探查达到状态/事件预算时返回未覆盖，不把截断遍历写成安全通过。

完成边界：逐课通过共享核心测试、模板验证、服务端判定，并在浏览器实际操作这十课；图纸双图可打开、元件可拖线、保存重载后仍能完成动作。十图已导入或十个菜单可点击都不代表十课仿真完成。

本轮后续实施进度：共享核心已实现本节所列六种元件、复合按钮微步骤、SQ 联动、虚拟时钟和两类六端电机；十套模板与独立评估模块已接入。核心测试已覆盖原四课及十套新模板，还有大步/分段时钟等价、暂停不推进、失电复位、绕组模式不同、浮动星点接 N、△ 零压绕组错误、额外负载耦合等反例。这里记录的是代码与核心测试结果，浏览器及整站最终验收由主任务分别记录，不因核心通过而提前宣称完成。

六端模型补充边界：任何没有直接源电位的绕组端或公共点若接入另一个线圈、灯或电机负载，返回 `UNSUPPORTED_MOTOR_LOAD_NETWORK` 并给出连接路径。即使原本符合低速/星形的端子分组，也不能忽略该额外负载后仍判正常；本模型不计算这类负载耦合的电压分配。

## 明确保留的限制

不模拟真实电磁/热/机械瞬态、惯性、换向冲击、负载转矩、实际电流、熔断曲线、相位不平衡或安装合规。定时值、工作台行程、接触器释放毫秒数和真实电机铭牌没有出现在图中；教学默认值必须可见，不能当作实物参数。已核验的外部 Δ/YY 连接足以建立离散识别，不足以推导任意厂家双速电机内部绕组、额定转速或真实功率。
