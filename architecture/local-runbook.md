## 启动和停止

### Windows 桌面一键启动（2026-09-30）

桌面快捷方式 **启动电拓智训** 会依次启动本机成员站和已配置的互联网隧道，验证就绪后打开本机网页并提示固定网址。电脑重启后双击一次即可；启动期间重复点击会提示等待，已有可用服务和隧道会直接复用。关闭网页不停止后台服务，关机后需重新双击启动。没有设置开机自动运行，也不要求管理员权限。

- 本机：`http://localhost:3000/`
- 其他联网设备：`https://train.titleone.space/`（无需同一局域网，仍需成员账号）
- 电脑必须开机、联网且不休眠；不要移动项目文件夹或删除 `.local/`、`.wrangler/state/`、`.dev.vars`。
- 启动日志及最近检查结果：`.local/desktop-launcher/`。若暂时断网，联网后再次双击；提示固定网址未验证成功时，不代表外网已经可用。
- 重新创建快捷方式：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-desktop-shortcut.ps1`。

快捷方式调用 `scripts/start-desktop.ps1`，后台复用下方两个启动器及既有持久化数据，不新增端口映射、防火墙放行或新的公网入口。执行策略参数仅作用于这一次脚本进程，不修改系统执行策略。

在项目根目录运行：

```powershell
npm install
npm run start:local
```

启动器会依次补充缺失的随机秘密、应用本地 D1 迁移、构建真实 API 界面、在 `127.0.0.1:3000` 启动 Worker，等待健康检查成功后创建或验证管理员。打开 `http://localhost:3000/`。保持终端运行，按 Ctrl+C 停止本次启动的进程树。

如果 3000 已有可用成员站，启动器直接提示现有地址，不写文件、不迁移、不重启。若端口被其他服务占用，启动器报错退出，不会抢占端口。当前命令仅监听本机 loopback；外网入口通过下方独立隧道转发，真实其他设备与不同运营商验收仍待完成。

前端修改后执行 `npm run build:local` 并刷新浏览器；Worker 后端源文件由 Wrangler 监听。`npm run dev` 保留 vinext 开发方式，但本机 Windows/Vite 8/vinext beta 的开发依赖优化曾出现长期高 CPU 和高内存、未监听端口的问题。稳定本地入口因此使用直接 Worker + 编译后的 React 界面，运行的仍是同一套真实 API、D1 和 R2。

历史 `server/local-server.mjs` 是旧三维训练服务器，保留为 `npm run legacy:start:local`，不是当前默认入口。它使用独立 `.local-training/` 数据，不能和当前成员站混用账号或数据库。

固定地址：`https://train.titleone.space/`。入口使用独立隧道 `diantuo-local-pc`，转发到 `http://127.0.0.1:3000`。现有 `edge.titleone.space` 与 VPS 隧道保持原配置。账号、草稿和课程图纸继续保存在这台电脑；公网入口使用同一套邀请成员权限。

### 2026-10-03 启动器的代理兼容修复

本机网页正常而启动器提示“固定网址连接尚未就绪”时，应先检查隧道日志。本次失败来自 Meta 虚拟网卡：Cloudflare 隧道端点被解析成 `198.18.*` 虚拟 IP，连接出现 QUIC 超时及 HTTP/2 TLS EOF。公网恢复前，本机 API 已返回 200，不能将该错误判断为数据库或网页启动失败。

`start:tunnel` 现在使用 HTTP/2。Windows 下自动选择具有默认 IPv4 路由的物理网卡，将本项目的连接绑定到该网卡；隧道启动器同时在随机 loopback UDP 端口运行专用 DNS 转发，将请求绑定到同一网卡后发给该网卡配置的 DNS。cloudflared 使用官方 `--edge-bind-address` 和 `--dns-resolver-addrs` 参数，继续动态查询 Cloudflare SRV/A/AAAA/TXT 记录，不固定 Cloudflare 节点 IP。DNS 转发随本次隧道结束而关闭，不修改系统 DNS、代理、路由或防火墙。

健康隧道仍直接复用。节点在启动首分钟内主动断开时，启动器最多进行三次串行连接，并重新查询节点；正常停止、程序无法执行或已运行超过一分钟后的退出不触发此重试。若需要重新连接，先核对具体进程的项目路径及参数，再只停止本项目的连接；切勿按程序名批量终止。恢复原行为只需撤回 `scripts/start-tunnel.mjs` 的此次改动，保留数据与秘密文件，再启动原连接。公网验证仍只代表当时的设备与网络。

`.dev.vars` 增加 `APP_PUBLIC_ORIGIN=https://train.titleone.space`，同时保留 `APP_ORIGIN=http://localhost:3000`。更改此文件后需重新启动本地服务。外网仅接受配置的 Host，要求 HTTPS，登录 Cookie 为 Secure、HttpOnly、SameSite=Lax，初始化管理员接口仅允许 loopback。不要把成员站直接改为监听公网地址。

官方 cloudflared 程序保存在 `.local/tools/cloudflared.exe`；连接凭据保存在 `.local/network-access/tunnel-token.txt`，通过 `--token-file` 读取。`.local/` 已被 Git 忽略，秘密不会进入公开构建。请安全保存这两个文件；不要复制令牌到聊天、日志、截图或代码。换电脑时需复制数据库及秘密，并重新配置唯一的本机连接，不能同时给独立数据库开两个相同隧道副本。

本次实际公网 HTTPS 验证：五个现有普通成员登录、会话回读、退出、管理员接口拒绝；十课二十张受保护图纸；两个成员的私有草稿隔离、保存回读、跨站写入拒绝和服务端检查。浏览器实际从端子拖到端子，并验证移动、缩放和刷新后全部导线的世界端点与端子一致；点动示范合闸后按住 SB2，KM1 吸合、电机运行，释放后 KM1 释放、电机停止。证据分别为 `.local/network-access/public-access.json`、`browser-wiring.json` 和 `browser-runtime.json`，验收临时服务器草稿与浏览器额外导线已清理，示范接线已恢复。

本机使用 `curl --noproxy '*'` 对固定域名完成了一次 DNS、TLS、HTTP 直连，约 1.75 秒返回正常会话结果；系统路由走 WLAN，未发现活动的 VPN/TUN 网卡。用户随后按要求用另一台电脑或手机关闭代理测试，反馈“能打开并登录”（运营商与设备型号未提供）。这些结果只代表所测设备、网络和时间；大陆其他运营商及长期可用性仍未验证。普通 Cloudflare 全球网络与 Cloudflare China Network 是不同服务，固定域名和 HTTPS 不提供“永远不会被 GFW 屏蔽”的保证。

恢复时先停止服务，把上述文件恢复到同一个项目位置，再执行 `npm run start:local`。`.local/app/` 是可重建界面资源，不是业务数据库；`docs/` 是 GitHub Pages 静态演示构建目录，不保存成员数据。

## 运行课程

先“开始仿真”，再点击QF合闸；按住按钮执行点动，松开恢复。连续控制按下再松开启动后保持，停止/过载TEST的效果取决于实际接线。SQ限位开关通过按住/松开手动触发，不虚构机床的行程位置。查看运行状态可以区分正转/反转、星形/三角形、低速/高速。

KT默认演示延时3秒，选中器件可改为0.1–600秒。原图没有规定具体秒数。运行时教学时钟自动推进，可暂停或逐秒推进；时间、接触器和保护动作都由同一引擎计算。不支持的接法会明确显示并打开诊断；不能把该提示当作运行或安全通过。

横向/纵向线槽可从器件库放入、移动、删除并随草稿保存，仅整理画布，不制造电气连接。导线交叉也不会自动相连。正式检查由服务端在副本中重算，运行状态、安全检查和课程动作分开展示；新增器件和超出课程覆盖的接法会明确标为未覆盖。

## 验证

```powershell
npm run typecheck
node --test tests/*.test.mjs
npm run build
npm run build:pages
```

默认后台验收使用独立的临时 Worker、D1、R2、管理员与随机端口，不读取现有站点凭据，也不写入现有数据库：

```powershell
npm run test:backend
# 保留本次临时数据与证据，便于复核
npm run test:backend -- --keep
```

该测试通过管理员创建两个随机验收成员，验证邀请竞争、私有草稿隔离、版本冲突、发布快照、赞/收藏/派生草稿、R2 附件权限与 Range、无效 multipart/伪 PNG、PDF 字节和预览头、十课服务端判分、共享图纸权限、退出登录和成员禁用。临时项目图纸关联会在测试结束时解除。测试成功默认只清理本次临时目录；失败或使用 `--keep` 时保留目录，路径由终端输出。测试结束会停止本次 Worker，保留目录不等于服务仍在运行。

目录内的 `artifacts/test-accounts.json` 含本次测试凭据，`artifacts/backend-acceptance.json` 为证据，均不得公开分享。普通 `node --test` 没有 `DIANTUO_TEST_URL` 时会跳过此集成测试，不能将该跳过计为通过。

只有明确需要在现有站点创建验收数据时才显式指定地址与管理员文件，例如：

```powershell
npm run test:backend -- --url http://localhost:3000 --admin-file .local/admin-access.json
```

这会在指定站点留下测试成员、草稿和作品，证据仍写入本次独立临时目录；它不是默认健康检查。隔离测试子进程移除继承的代理环境变量，以避免本机 D1 命令结束后代理句柄阻止退出；不更改父进程或系统代理。显式现有站点模式保留原代理环境。

重启持久化验收脚本支持与集成测试相同的目录变量。先重启对应的隔离Worker（使用原配置、原 `--persist-to` 与原origin；不要为此重启现有业务服务），再指定本次保留目录：

```powershell
$env:DIANTUO_TEST_ARTIFACT_DIR = '<本次临时目录>/artifacts'
$env:DIANTUO_TEST_ADMIN_PATH = '<本次临时目录>/admin-access.json'
$env:DIANTUO_TEST_URL = 'http://127.0.0.1:<本次测试端口>'
node scripts/test-persistence.mjs
# 验收后清除当前终端的测试变量，避免影响其他命令
Remove-Item Env:DIANTUO_TEST_ARTIFACT_DIR, Env:DIANTUO_TEST_ADMIN_PATH, Env:DIANTUO_TEST_URL
```

脚本验证三个账号登录、草稿与PNG/PDF的SHA-256、跨成员拒绝访问，并将 `persistence-acceptance.json` 写入选定产物目录；每个请求限时15秒。没有设置变量时，仍兼容旧 `.local/backend-acceptance.json`、`.local/test-accounts.json` 和 `.local/admin-access.json`，不能把不同数据库的证据和账号文件混用。本轮已在临时库重启后验证通过，未重启现有业务服务。这是同一临时库的重启验证，不是生产备份恢复演练。API和哈希验收不替代浏览器拖线、开关、上传预览与仿真验收。

完整 API 契约见 `app/server/README.md`。生产配置需要正式 D1/R2、HTTPS 域名和单独秘密，不复用本地示例数据库标识。

## 器件动作与带电提示

开始仿真后直接点击空开蓝色手柄切换合分闸（上方I为合、下方O为分），直接按住红/绿按钮帽操作，松开复位。电机受电后仅风叶旋转；方向和双速快慢来自电气引擎状态，停止时风叶立即暂停。启用系统减弱动态偏好时，保留静态方向和速度提示。

导线和端子的高亮表示计算得到的带电范围；分闸后断路器上游进线仍带电。动画快慢不是实测转速，高亮也不表示真实电流大小。

Tailwind扫描范围已限定为`app/`与`github-pages/`，避免扫描`docs/`生成包或静态资源时内存膨胀。原三维源码仍在`app/`扫描范围内，不因此丢失其样式。

## 2026-09-30 图纸查看与账号补充

工作台右侧图纸窗可拖动标题、收起和按50%–200%缩放；标题复位按钮恢复位置与大小。点击“放大查看”单独打开原图，按100%–300%放大后可拖动或滚动查看。“选择项目图纸”展开项目选择、刷新及管理员上传选项。仿真期间可浏览其他图纸，应用图纸和上传仍锁定。

个人中心增加“修改密码”入口：当前密码验证、新密码12–128字符、二次确认；可选择退出其他设备登录。真实账号密码由使用者自行填写修改，自动验收仅检查了表单与模拟API反馈。

## 工作台布局与成员广场

电路标题、课程切换、载入示范及新建入口在画布左上方“课程与草稿”中展开；开始仿真后这些编辑操作仍锁定。元件池默认按家庭、工业及接线辅助分组，点击标题旁放大镜展开搜索。电脑端工具栏空间不足时可横向滚动查看导入导出及撤销重做。

成员广场按标题、说明或作者搜索，每页12个作品。作品详情地址包含作品ID、搜索词与页码，可刷新恢复，也可复制给已经登录的成员；这不扩大附件或草稿的访问权限。复制练习会在本人账号下建立草稿。作品发布快照仍独立于后续草稿修改。

参考图纸预览新增“教学视频”：有资源的图纸可直接在线播放、调倍速、前后跳转10秒，并使用浏览器播放控件。工作台为当前选中的原站参考图显示其对应视频；上传图纸、十套正式项目及浏览其他项目时不自动套用这些视频。视频仍来自原媒体地址，需要网络，没有打包为离线内容。

## 三联熔断器与红绿自锁/复位按钮

工业器件池现有“三联熔断器（FU）”：一次放入，六端子分别连接三相。十课新练习和示范默认使用这款 FU1；旧三只单极熔断器草稿不需要转换，课程检查仍接受。

红色、绿色各提供复位与自锁两种按钮。复位按钮按住动作、松开弹起；自锁按钮点击保持、再次点击弹起。每种颜色均含常闭和常开触点，不按颜色判断接通路径。用户可在个人草稿“**三联熔断器与红绿按钮 · 操作演示**”中操作四个按钮观察灯与高亮；刀开关断开后下游熄灭，保持按钮仍保持机械位置。

浮窗左下“选择图纸”提供18张原站参考图，确认后保留接线并切换对应图/视频，选择会随草稿保存。换成另一张参考图会退出原课程判定；“图纸集→课程图纸”仍是十套正式课程入口。入口链接和存档规则见 `reference-drawing-flow.md`。
