# 聊天反馈十项修改与验收

2026-10-02，按用户批准的计划完成现有二维仿真修改，并使用本地完整站 `http://localhost:3000/` 验证。原始 SVG、旧三维代码和模型、原有成员草稿及正式项目图纸保留。浏览器验收使用独立测试账号和测试草稿。

## 完成情况

| 项目 | 实现及实测结果 |
| --- | --- |
| 图纸大小 | 浮窗八个边/角可拖动调整，图纸独立缩放 50%–400%，支持页内全屏和 Esc 退出；选项目后自动收起选项。1366×768、1920×1080 均检查了原理图、布置图、保存/检查按钮可达性，放大后实际拖看。个人 PNG 和 PDF 均验证。 |
| KM 重复标号 | 删除 Handle 额外叠加文字，保留原图印刷标号；教学 KA、KT 等特殊标号保持。派生资源回归逐条核对原图文字和电气路径。 |
| 线槽尺寸 | 横向、纵向可独立拖长宽，尺寸范围 24–4000 世界单位；一次手势一次撤销。实测横槽 540×100、纵槽 92×468，撤销/重做、再次移动、保存重载均保持尺寸。运行时尺寸手柄关闭。 |
| 端子比例 | 普通端子和 PE 端子的资产尺寸与所有局部端子坐标均乘 0.75，端子 ID 和电气导通关系保持；旧导线引用继续有效。 |
| 电机动画 | 普通 0.6 秒/圈，双速低速 0.8 秒/圈、高速 0.4 秒/圈；浏览器核对了实际 CSS 动画速度、正反转及停止状态。动画仅表示教学状态。 |
| 接线端点 | 三种线形均实际从端子拖到端子。导线世界端点与端子严格相等；移动、缩放、保存重载后保持。端子屏幕圆心也与世界坐标的画布变换一致。线头在原图上方显示，避免被遮挡。 |
| KM 吸合 | 原图中间四块变红，中央白字「吸合」随实际状态显示；按钮松开、停止、过载和失电释放。保留原图。 |
| 导线显示 | 普通 3px、选中 4px，线头同步，透明度为 1，缩放时保持显示宽度。浏览器验证自定义紫色仍保留；新线和课程模板使用更鲜明的默认色。 |
| 短路告警 | 居中红黄警告、红色遮罩、通路定位。启动短路、合闸产生短路以及相间/相零/相地三类故障均检查。同一故障只提示一次，确认后继续锁存并断电；新会话重新提示。缺 PE 提醒不触发此弹窗，电机状态由接线求解。 |
| 端子黑点 | 移除圈出的四个装饰槽点，每个可接线端子有中心指示点。实测相线带电变红，N、PE、失电及结束仿真恢复黑色，不按线色判定。 |

撤销/重做同时修复了 React 延迟执行状态更新时读取错误文档快照的问题；新增回归覆盖该时序。上传个人图纸后原项目预览残留、短路按钮被页面通用样式覆盖的问题也已通过实际浏览器复现并修复。

## 课程与数据验收

| 课程 | 实际浏览器动作及服务端判定 |
| --- | --- |
| 01 点动 | 按住运行，松开停止；通过。 |
| 02 连续 | 启动保持、停止、FR TEST/RESET；通过。 |
| 03 点动与连续 | 连续运行及点动、点动释放切断保持；通过。 |
| 04 接触器互锁 | 运行中反向请求受阻，停止后反向；通过。 |
| 05 双重联锁 | 正向切到反向、停止；通过。 |
| 06 自动往返 | SQ1/SQ2 换向，SQ3 越程停止；通过。 |
| 07 顺序 | 先启动 M1 再 M2，逆序停止；通过。 |
| 08 延时 | 2 秒未启动，3 秒运行，停止；通过。 |
| 09 Y-Δ | 星形启动、3 秒后切换三角形、停止；通过。 |
| 10 双速 | 低速 Δ、高速 YY、停止及动画速率；通过。 |

所有十课同时运行了完整引擎回归及服务端逐课行为判定。以上浏览器动作是实际操作记录，不代表所有任意接法的穷举。

新线槽尺寸通过真实草稿保存、发布快照和另一账号打开的只读预览验证；后台拒绝宽度 23 的越界文档（HTTP 400）。保持 `schemaVersion:1`，旧文档默认尺寸与新尺寸均接受共享校验器检查。

两个独立成员登录后，私有草稿和个人 PNG/PDF 被另一账号访问时返回 404；正式项目原理图、布置图允许两个成员读取（200），成员替换项目图纸返回 403，匿名读取返回 401。全部正式项目图纸已存在，未替换原图。
