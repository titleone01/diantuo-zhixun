# 电拓智训

面向职业院校电气自动化、电工电子和机电一体化等专业的虚拟接线实训平台原型。

当前演示以“三相异步电动机连续运行/自锁控制电路”为例，学生可对照原理图，在实物化元器件面板上完成主电路、控制电路和保护接地接线。

## 在线测试

[https://titleone01.github.io/diantuo-zhixun/](https://titleone01.github.io/diantuo-zhixun/)

## 已实现

- 原理图查看与放大
- QF、FU、KM、FR、SB1/SB2、电动机和 XT 端子排实物化展示
- 端子热点与真实端子编号
- 鼠标拖线、触摸接线和键盘操作
- 主电路、控制电路和保护接地导线分类
- 撤销、清空、逐步提示和通电检查
- 错接、漏接反馈及电动机运行状态

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

默认访问地址为 `http://localhost:3000`。

## 验证构建

```bash
npm run build
```
